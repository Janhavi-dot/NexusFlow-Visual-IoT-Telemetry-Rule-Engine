
# NexusFlow
### Visual IoT Telemetry & Rule Engine

NexusFlow is a visual IoT telemetry and rule engine that allows users to design sensor-based workflows using a drag-and-drop interface.

## Technology Stack

### Frontend
- React
- Vite
- React Flow (@xyflow/react)

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose

## Project Structure

- backend/ - Backend server and APIs
- frontend/ - React workflow editor
